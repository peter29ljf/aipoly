**运行周期**：2026-06-29 → 2026-08-31（约 2 个月，每日 UTC 09:00 自动扫描）
**最终状态**：已停止。累计敞口 $1,505 全部损失 —— **非交易判断失误，而是私钥泄露导致资产被盗**。

## 一、策略定义

捕获高概率市场（85–97%）临近结算时最后几个百分点的 ROI。赌的是"市场在结算前对接近确定的结果仍有轻微低估"。

| 参数 | 值 |
|------|-----|
| 概率区间 | 0.85 ≤ p ≤ 0.97 |
| 到期窗口 | days ≤ 7（候选少时放宽到 30 天） |
| 入场 ROI 门槛 | ≥ 8% |
| 流动性门槛 | ≥ $5,000 |
| 单笔金额 | $50（政治类可到 $100） |
| 每日上限 | 最多 5 笔新仓 |
| 止损 | **无**（见第三节，已被 6 个案例验证） |
| 排除类别 | 体育博彩、加密货币价格、马斯克推文、油价金价、股价/指数/贵金属 |
| 优先类别 | politics（选举初选）> geopolitics > macro |
| 硬性禁止 | `days_left = 0` 的市场（流动性差，难成交） |

## 二、真实收益率：记录纠错与基准对照

### 1. 归零是 5 笔，不是 2 笔——其中 2 笔曾被误记为获胜

2026-07-24 用链上 `redeemable` / `currentValue` 字段逐笔核对时发现：

| 标的 | 历史记录 | 链上真实结果 |
|------|---------|-------------|
| Exactly 10 earthquakes 5.5+ June29–July5 = No | ❌ 误记为「✅ 赢 +8.7%」 | **实际归零**（地震数恰好 = 10） |
| Highest temp Warsaw 20°C July4 = No | ❌ 误记为「✅ 赢 +9.29%」 | **实际归零**（气温恰好 = 20°C） |

**根因**：到期当天直接「预计获胜」移除持仓记录，未等链上确认结算方向。

**已成为固定规则**：任何持仓移除前必须先用 `get_positions` 核实 `redeemable=true`，
再按 `currentValue` 判断输赢（= 0 则输，≈ size 则赢），**不得凭到期日推测**。

链上确认的完整归零记录（共 5 笔）：

| # | 标的 | 到期 | 主题分类 |
|---|------|------|---------|
| 1 | Iran successfully targets shipping on July 7 | 7/7 | 中东航运/伊朗突发事件 |
| 2 | Fewer than 150 ships transit Hormuz July6–12 | 7/12 | 中东航运/伊朗突发事件 |
| 3 | "The Odyssey" opening weekend box office > 115M | 7/19 | 娱乐票房预测 |
| 4 | Exactly 10 earthquakes 5.5+ June29–July5 | 7/5 | 精确数值型自然事件 |
| 5 | Highest temp Warsaw 20°C July4 | 7/4 | 精确数值型自然事件 |

### 2. 账目从未对平，净盈亏无法从记录反推

文档中反复出现 `未能完全对账`：

- 7/30：余额跳升 $161.11，但 Fed 仓位赎回只能解释 $53.76
- 8/13：余额跳升 $485.73，6 笔成本合计 $400，差额约 $51 无解释
- 8/7：两笔理论赎回约 $163，实收 $107.55

这些差额被归因为「可能为用户追加入金」。**入金与盈利混在同一个余额里，P&L 无法反推。**
`memory.md` 里「净收益约 +$90」是在错误的胜负记录 + 对不平的账上算出来的，不可引用。

**新部署必须解决**：入金/出金单独记账，与交易盈亏分离，否则永远不知道策略到底赚没赚。

### 3. 核心算术：8% 不是利润，是承担归零风险的对价

以 0.92 买入、结算 1.00：赢 **+8.7%**，输 **−100%**。

**盈亏平衡的归零率 = 买入价隐含的概率 = 8%。** 计入 1–3% 滑点后实际买在 0.94，
平衡点降到 **6%**。也就是说：每 100 笔里归零超过 6–8 笔，这个策略就是亏的。

| 阶段 | 结算笔数 | 归零 | 归零率 | 对比平衡点 6–8% |
|---|---|---|---|---|
| 6/29–7/23（类别规则上线前） | ~10 | **5** | ~50% | 🔴 远超，大幅亏损 |
| 7/24–8/31（类别规则上线后） | ~20 | **0** | 0% | 🟢 达标 |

**5 笔归零全部集中在第一个月。** 7/24 上线「主题三振 + 排除精确数值区间 + 链上核实」
三条规则后的六周内零归零——策略确实学会了。

**但样本量不足以下结论**：第二阶段只有约 20 笔，而平衡点是 6%。
20 笔中出现 0 次归零，与真实归零率 5% 的假设完全相容。**不能据此认为已经跑赢平衡点。**

### 4. 学术基准：真实 edge 比「8% ROI」小一个数量级

arXiv《The Favorite–Longshot Bias in Prediction Markets: Evidence from Polymarket》
基于 **5870 万笔交易 / $96.6 亿成交额**的实证结果，买入 p ≥ 0.90 合约的真实收益：

| 口径 | 收益 |
|------|------|
| 等权（按子市场） | **+0.277%**（95% CI 0.242–0.312%） |
| 池化（按金额加权） | **+0.83%**（95% CI 0.60–1.07%） |
| 等权（按父事件） | **+0.392%**（95% CI 0.345–0.440%） |

分类别（等权 / 池化）：

| 类别 | 收益 | 本策略的处理 |
|------|------|-------------|
| **Politics** | **+1.044% / +1.419%**（最高） | ✅ 定为最高优先级 |
| Crypto | +0.643% / +0.537% | ✅ 已排除 |
| Finance | +0.085% / +1.826% | — |
| **Sports** | **−0.230% / +0.137%**（唯一负值） | ✅ 已排除 |

**两条独立摸索出的规则（politics 优先、sports 排除）与 5870 万笔交易的实证结论完全一致。**

**但结论也很残酷**：买 p ≥ 0.90 的真实 edge 只有 **0.3%–1.4%**，不是 8%。
论文明确说明该数字**不含手续费与滑点**。

而本策略实测滑点：香港温度 **2.13%**、Hormuz **2.76%**、Core CPI **3.05%**、Samara 直接无法成交。

> ### 🔴 滑点（1–3%）比整个 edge（0.3–1.4%）还大。
>
> 这一条解释了全部问题：不是选标的能力不行，是**执行成本吃掉了甚至超过了全部理论优势**。

社区中同构的打法称为 **"Endgame Sweep"**，标准做法是买 **$0.95–0.99** 而非 0.85–0.97，
其描述用的词是「捡基点（basis points）」——不是百分点。网上流传的「$313 变 $414,000」
一类战绩，检索结果本身即提示：每周都有人发布此类 AI bot 暴富故事，应默认存疑。

## 三、被验证有效的做法

### 1. 无止损规则 —— 这是整个策略最反直觉但最正确的一条

浮亏不是卖出信号。高概率市场在结算前的价格波动，大部分是噪音而非信息。**有 6 个反转案例全部最终获胜**：

| 标的 | 最深浮亏 | 结果 |
|------|---------|------|
| Russell Fry | −26.9% | ✅ 获胜 |
| Belinda Keiser | −25.8% | ✅ 获胜 |
| Marlene Galán-Woods | −20.5% | ✅ 获胜 |
| Brian Mundubile | −12.7% | ✅ 获胜 |
| Tidö 联盟（瑞典） | −9.9% | ✅ 获胜 |
| Aisha Wahab | −7.4% | ✅ 获胜 |

**结论**：持有至链上赎回。中途割肉会把"噪音波动"兑现成"真实亏损"。

### 2. 集中度限制：同一事件族只押一个方向

反复触发、反复生效。典型排除：
- São Tomé 总统选举：已持 `Nito Abreu=No`，则排除 `Carlos Vila Nova=Yes`（ROI 11.11% 也不要）
- AZ-01 民主党初选：已持 `Marlene Galán-Woods`，排除同选区其他候选人
- Samara 与 Astrakhan 州议会："小党不会赢俄罗斯州议会" + 同为 9/20 统一投票日 = **本质同构**，共享"统一俄罗斯全面主导"这一系统性风险，只取 ROI 更高的一个

**要点**：同构判定不能只看市场名称，要看**底层风险来源是否同一个**。

### 3. 主题"三振"拉黑

中东航运/突发袭击主题（Hormuz、Bab el-Mandeb、Iran attacks shipping）在 7/6、7/12 **两次反转归零**后，此类候选无论 ROI 多高一律规避 —— 后续几十条 ROI 9%+ 的同主题候选全部排除。

**要点**：这类市场的风险不是"概率算错了"，而是**突发事件本身不可预测**，历史概率无参考价值。同理适用于"窄数值区间型"（精确地震数、具体气温、CPI 具体值、退休人数区间）—— 已 2 次归零。

### 4. 优先流动性而非 ROI

Fed 7 月议息市场流动性 $855k（全场最高），scan ROI 8.11%、成交后 7.53%，略低于门槛仍然入场 —— 因为滑点风险极低、确定性优秀。反之，ROI 11% 但 liq $5-8k 的财报类标的一律跳过。

## 四、踩过的坑

### 1. ⚠️ 最大的系统性问题：scan 的 ROI 是"中间价 ROI"，不是"可成交 ROI"

`scan` 返回的 `p` 和 `ROI` 来自 Gamma 侧的中间价估算，**与真实可成交盘口严重脱节**。实际滑点反复吃掉入场优势：

| 日期 | 标的 | scan ROI | 实际 ROI | 滑点 |
|------|------|---------|---------|------|
| 7/4 | 香港 29°C | 8.7% | **4.17%** | 2.13% |
| 7/6 | Hormuz <150 ships | 9.89% | **7.53%** | 2.76% |
| 7/15 | Core CPI 2.7% | 9.05% | **5.71%** | 3.05% |
| 8/26 | Samara 州议会 | 10.68% | **市价单直接被拒** | 盘口实际为空 |

**规律**：`liq` 越接近 $5k 门槛、越临近到期、类别越冷门（温度/CPI/小国地方选举），滑点越大。**流动性数字本身也可能是虚报的** —— 8/26 的 Samara 候选 scan 显示 liq $8.43k、mid 0.9035，实际卖盘只有 0.998/0.999 两档共 936 shares，买盘最优 0.011，即挂单簿实质为空。

**应对**：
- `liq > $10k` 才考虑窄口径数值区间市场
- 滑点 > 2% 的标的谨慎入场，> 3% 直接放弃
- **优先用 `limit_buy` GTC 挂单代替市价单**（见下一条）

### 2. `get_orderbook` 的可信度：认知反复了两次，最终结论是"能用但要会读"

- **7/9**：发现 `get_orderbook` 返回的档位与 scan 概率差距极大（asks 集中在 0.95–0.99），一度判定"数据不可信/非真实盘口"，并据此决定**不再依赖该工具做入场判断**。
- **8/26**：市价单被拒（"滑点范围内无可用深度"），回头查 `get_orderbook`，**证实它是对的** —— 盘口确实是空的，错的是 scan 的 liq/mid。

**正确理解**：`get_orderbook` 反映真实可成交深度，`scan` 的 liq/mid 是估算值。两者不一致时，**以 orderbook 为准**。7/9 的结论是错的，代价是之后一个多月持续吃滑点。

### 3. 限价单：7/13 就提出，8/26 才首次执行

策略文档从 7/13 起多次写下"改用 limit_buy 控制成交价"的建议，但**一个多月没有执行**，期间持续承受 2–3% 滑点。

首次执行（8/26 Samara，挂 0.905 / 75 shares / $67.88）的新问题：**GTC 挂单会长期占用资金且可能永不成交**，8/27 即撤单释放。

**结论**：限价单是对的方向，但要配套"挂单超时撤销"规则，否则在资金紧张时会锁死额度。

### 4. 资金管理：$50 的最小建仓门槛会卡死策略

7/28、7/31 两次出现余额仅 $14.93 / $16.16，**不足单笔建仓门槛**，而当天扫描出了多个高质量候选（Iran MOU withdrawal ROI 10.5% liq $94k、AZ-01 Jay Feely ROI 11.11% liq $25k 等）全部只能搁置，等待到期回款。

**结论**：需要预留现金缓冲，或按余额动态调整单笔金额下限。满仓运作会让策略在最好的机会面前没钱。

### 5. 逾期未赎回的仓位会静默累积

被盗时有 4 笔早已到期但未赎回（Tukaka George 8/12、Adam Crum 8/18、Ken Welch 8/18、Vindman 8/18）。**赎回不是自动的**，需要显式操作，否则资金一直锁在已结算的 token 里。

## 六、改进优先级

按「对期望收益的影响」排序。第 1 条是唯一能让 edge 转正的措施。

### 🔴 P0 — 限价单常态化

`limit_buy` GTC 挂单代替市价单，消除 1–3% 的滑点税。**这是决定策略生死的一条**：
edge 只有 0.3–1.4%，滑点不消除，做多少笔都是负期望。

策略文档自 7/13 起多次写下这条建议，**直到 8/26 才首次执行**，期间持续承受滑点。

配套规则（8/26 首次使用即暴露的问题）：挂单会长期占用资金且可能永不成交
（Samara 单笔锁住 $67.88，次日撤单）。需要**挂单 N 小时未成交自动撤销**。

### 🔴 P0 — 入场门槛改用「滑点后 ROI」

现行 ROI ≥ 8% 是拿 Gamma 中间价算的，与真实可成交价脱节，等于没有门槛。改为：

- 以 `get_orderbook` 的真实最优价计算 ROI，而非 scan 的 `mid`
- 硬性要求 `liq > $10k`（窄口径数值区间市场尤其）
- 滑点 > 2% 谨慎，> 3% 直接放弃

### 🟠 P1 — 价格区间上移到 0.95–0.99

社区 endgame sweep 的标准区间。单笔更薄，但持有期更短、资金周转更快、归零概率更低。
考虑到真实 edge 本就是基点级别，**周转率比单笔幅度更重要**。

### 🟠 P1 — 仓位分散

$50/笔 在 $500 资金池上是 10% 集中度，而单笔下行是 **−100%**。
在归零率 6% 的生意里，仓位大小就是生死线。应大幅降低单笔占比、增加笔数。

同时解决「资金耗尽卡死」问题：7/28、7/31 两次余额不足 $50 建仓门槛，
眼看着 ROI 10%+ 的候选无法执行。

### 🟡 P2 — 赎回自动化

被盗时有 4 笔早已到期未赎回（Tukaka George 8/12、Adam Crum 8/18、Ken Welch 8/18、
Vindman 8/18）。赎回不是自动的，资金会静默锁在已结算的 token 里。

### 🟡 P2 — 入金/出金独立记账

与交易盈亏分离（见第二节第 2 点）。否则永远无法知道策略是否真的盈利。

### ✅ 保持不动

- **无止损规则** —— 6 个深度反转案例全部翻回，已验证
- **类别过滤（politics 优先 / sports、crypto 排除）** —— 与 5870 万笔交易的实证结论一致
- **主题三振拉黑 + 集中度限制** —— 上线后六周零归零

3. **后端以 root 运行** → 改用专用用户 + systemd 沙箱（`ProtectHome=yes` / `NoNewPrivileges=yes`）。
   本仓库同机的 PinChat 用 `systemd-run --uid=... --property=ProtectHome=yes` 做了正确示范，aipoly 侧从未应用。
4. **`/api/*` 完全无鉴权**（`.token` 只守 `/_internal`）→ 加真实鉴权。
   当前只靠反向代理的 basic_auth 兜底，而 loopback 站点（SSH 隧道入口）连这层都没有。
5. **CORS `allow_origins=["*"]`** → 收成白名单。
   配合 SSH 隧道，任何网站在浏览器里都能跨域驱动后端，**无需任何凭证**。
6. **agent 的 `--allowedTools` 含 `Bash,Write` 且 `--permission-mode acceptEdits`** → 去掉 `Bash,Write`。
   策略 agent 的工作全在 `mcp__poly_trade__*` / `mcp__portfolio__*` 里，不需要 Bash。
   保留 Bash 意味着：**一条聊天消息 = root 任意命令**，且 agent 读取的外部行情文本可构成提示词注入。

### 强烈建议
7. **改用 session key / 受限权限密钥**，使服务器上的密钥即使泄露也**无法转走本金**（参考 commit `07139f9`）。这是唯一能把"密钥泄露"从灾难降级为事故的措施。

### 恢复前提（缺一不可）
1. 旧钱包 `0xCE1001c3...`、私钥、CLOB API key **永久作废**，**绝不再充值**（sweeper 仍在监控该地址，几美元也会被扫走）
2. 生成全新钱包，重建 Polymarket 代理钱包与 CLOB 凭证
3. 完成上面 1–7 项加固
4. 验证 `get_balance` / `get_positions` 正常返回
5. 之后才可重建 `strategy-auto` 定时任务

## 八、给新部署的一句话总结

**选标能力是三者里最健康的。** 7/24 上线的类别规则之后六周零归零，
politics 优先与 sports 排除两条独立结论与 5870 万笔交易的学术实证完全一致。

**但按当前执行方式，这是个负期望的生意。** 真实 edge 只有 0.3–1.4%，
而实测滑点 1–3%。不先解决执行成本（第六节 P0），做多少笔都是在给滑点交税。

**而真正的风险从来不在交易台上。** 两个月交易最乐观赚 $90，
一次私钥泄露亏 $1,505 —— **运维事故的成本是全部利润的 17 倍**。

新服务器上重启时的顺序：先做完第七节的安全清单，再做第六节的 P0 执行改造，
最后才开第一笔仓。反过来做，等于用更高的效率重复同一个错误。
